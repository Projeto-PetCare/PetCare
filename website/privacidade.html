Política de Privacidade

Versão preliminar — Novembro de 2026

1. Apresentação

Esta página apresenta informações sobre o tratamento de dados pessoais no projeto acadêmico PetCare.

2. Dados solicitados

A interface de Contato solicita nome, e-mail, assunto e mensagem.

A interface de Login solicita e-mail e senha para uma futura autenticação de funcionários.

O sistema de gestão também prevê informações sobre animais e seus responsáveis.

3. Finalidade dos dados

Os campos foram projetados para demonstrar funcionalidades de contato, identificação de usuários e gestão de registros veterinários.

4. Armazenamento e segurança

As funcionalidades de armazenamento e autenticação estão sujeitas à implementação e aos testes do sistema.

As medidas efetivamente utilizadas deverão ser documentadas antes da disponibilização da plataforma para usuários reais.

5. Dados reais e testes

Durante o desenvolvimento acadêmico, recomenda-se utilizar informações fictícias nos testes e demonstrações.

6. Direitos e solicitações

Informações sobre solicitações relacionadas a dados pessoais poderão ser obtidas pela página de Contato .

7. Atualizações

Este texto poderá ser revisado conforme novas funcionalidades forem implementadas.
